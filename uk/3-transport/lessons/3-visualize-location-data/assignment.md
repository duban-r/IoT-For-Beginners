# Розгорніть свій застосунок

## Інструкції

Розгорнути застосунок, щоб поділитися ним зі світом, можна кількома способами: через GitHub Pages або через одного з багатьох постачальників сервісів. Дуже зручний спосіб — Azure Static Web Apps. У цьому завданні зберіть свій вебзастосунок і розгорніть його в хмарі за [цими інструкціями](https://github.com/Azure/static-web-apps-cli) або переглянувши [ці відео](https://www.youtube.com/watch?v=ADVGIXciYn8&list=PLlrxD0HtieHgMPeBaDQFx9yNuFxx6S1VG&index=3) (англійською).
Перевага Azure Static Web Apps у тому, що ключі API можна сховати в порталі, тож скористайтеся нагодою: винесіть subscriptionKey у змінну й зберігайте його в хмарі.

## Критерії оцінювання

| Критерій | Відмінно | Достатньо | Потребує покращення |
| -------- | -------- | --------- | ------------------- |
|          | Робочий вебзастосунок представлено в задокументованому репозиторії GitHub, subscriptionKey зберігається в хмарі та використовується через змінну | Робочий вебзастосунок представлено в задокументованому репозиторії GitHub, але subscriptionKey не зберігається в хмарі | Вебзастосунок містить помилки або працює неправильно |
