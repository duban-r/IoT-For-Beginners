# Надсилайте сповіщення через Twilio

## Інструкції

Поки що ваш код лише записує в журнал відстань до геозони. У цьому завданні потрібно додати сповіщення — текстове повідомлення (SMS) або електронний лист, — коли GPS-координати всередині геозони.

Azure Functions має багато варіантів прив'язок, зокрема до сторонніх сервісів, як-от комунікаційної платформи Twilio.

* Зареєструйте безкоштовний обліковий запис на [Twilio.com](https://www.twilio.com).
* Прочитайте документацію про прив'язку Azure Functions до Twilio SMS на сторінці [Twilio binding for Azure Functions на Microsoft Learn](https://learn.microsoft.com/azure/azure-functions/functions-bindings-twilio?tabs=python).
* Прочитайте документацію про прив'язку Azure Functions до Twilio SendGrid для надсилання електронних листів на сторінці [Azure Functions SendGrid bindings на Microsoft Learn](https://learn.microsoft.com/azure/azure-functions/functions-bindings-sendgrid?tabs=python).
* Додайте прив'язку до свого застосунку Functions, щоб отримувати сповіщення, коли GPS-координати всередині геозони або поза нею, але не в обох випадках.

## Критерії оцінювання

| Критерій | Відмінно | Достатньо | Потребує покращення |
| -------- | --------- | -------- | ----------------- |
| Налаштування прив'язок функцій і отримання листа чи SMS | Налаштовує прив'язки функцій і отримує лист чи SMS, коли координати всередині геозони або поза нею, але не в обох випадках | Налаштовує прив'язки, але не може надіслати лист чи SMS, або надсилає їх і коли координати всередині, і коли поза геозоною | Не може налаштувати прив'язки й надіслати лист чи SMS |
