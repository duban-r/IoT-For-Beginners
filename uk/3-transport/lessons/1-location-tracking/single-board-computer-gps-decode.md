# Декодування GPS-даних: віртуальний IoT-пристрій і Raspberry Pi

У цій частині уроку ви декодуватимете NMEA-повідомлення, які Raspberry Pi або віртуальний IoT-пристрій зчитує з GPS-сенсора, і витягнете з них широту й довготу.

## Декодування GPS-даних

Сирі NMEA-дані, прочитані з послідовного порту, можна декодувати за допомогою бібліотеки NMEA з відкритим кодом.

### Завдання: декодуйте GPS-дані

Запрограмуйте пристрій так, щоб він декодував GPS-дані.

1. Відкрийте проєкт застосунку `gps-sensor`, якщо його ще не відкрито.

1. Встановіть pip-пакет `pynmea2`. Він містить код для декодування NMEA-повідомлень.

    ```sh
    pip install pynmea2
    ```

1. Додайте до імпортів у файлі `app.py` такий рядок, щоб імпортувати модуль `pynmea2`:

    ```python
    import pynmea2
    ```

1. Замініть вміст функції `print_gps_data` на такий:

    ```python
    msg = pynmea2.parse(line)
    if msg.sentence_type == 'GGA':
        lat = pynmea2.dm_to_sd(msg.lat)
        lon = pynmea2.dm_to_sd(msg.lon)

        if msg.lat_dir == 'S':
            lat = lat * -1

        if msg.lon_dir == 'W':
            lon = lon * -1

        print(f'{lat},{lon} - супутників: {msg.num_sats}')
    ```

    Цей код за допомогою бібліотеки `pynmea2` розбирає рядок, прочитаний з послідовного UART-порту.

    Якщо тип речення — `GGA`, то це повідомлення з визначеним місцеположенням, і код його обробляє. Широту й довготу зчитують із повідомлення та перетворюють із NMEA-формату `(d)ddmm.mmmm` у десяткові градуси. Це перетворення виконує функція `dm_to_sd`.

    Потім перевіряється напрямок широти: якщо широта південна, значення стає від'ємним. Так само з довготою: якщо вона західна, значення стає від'ємним.

    Нарешті координати виводяться в консоль разом із кількістю супутників, за якими визначено місцеположення.

1. Запустіть код. Якщо ви використовуєте віртуальний IoT-пристрій, переконайтеся, що застосунок CounterFit запущено і він надсилає GPS-дані.

    ```output
    (.venv) ➜  gps-sensor python app.py
    47.6423109,-122.1390293 - супутників: 3
    ```

    > 💁 Якщо програма завершується з помилкою `pynmea2.nmea.ChecksumError`, ви вставили в CounterFit NMEA-речення з неправильною контрольною сумою (останні символи після `*`). Згенеруйте речення заново, наприклад на [nmeagen.org](https://www.nmeagen.org), або скористайтеся джерелом `Lat/Lon`.
