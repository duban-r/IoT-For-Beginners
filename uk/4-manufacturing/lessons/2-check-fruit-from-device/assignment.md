# Відреагуйте на результати класифікації

## Інструкції

Ваш пристрій класифікував зображення й отримав значення передбачень. Пристрій може використати цю інформацію, щоб щось зробити: надіслати її в IoT Hub для обробки іншими системами або керувати актуатором, наприклад увімкнути світлодіод, коли фрукт недостиглий.

Додайте до коду пристрою реакцію на свій вибір: надішліть дані в IoT Hub, керуйте актуатором або поєднайте обидва варіанти: надсилайте дані в IoT Hub, де безсерверний код визначає, достиглий фрукт чи ні, і надсилає назад команду для керування актуатором.

> 💁 Без Azure можна зробити те саме локально: наприклад, увімкнути світлодіод CounterFit (як у [розділі 1, урок 3](../../../1-getting-started/lessons/3-sensors-and-actuators/virtual-device-actuator.md)), коли найімовірніший клас — `unripe`, або надіслати результат через MQTT (як у [розділі 1, урок 4](../../../1-getting-started/lessons/4-connect-internet/README.md)).

## Критерії оцінювання

| Критерій | Відмінно | Достатньо | Потребує покращення |
| -------- | --------- | -------- | ----------------- |
| Реакція на передбачення | Зміг реалізувати реакцію на передбачення, яка стабільно працює для передбачень з однаковим значенням | Зміг реалізувати реакцію, яка не залежить від передбачень, наприклад лише надсилання необроблених даних в IoT Hub | Не зміг запрограмувати пристрій реагувати на передбачення |
