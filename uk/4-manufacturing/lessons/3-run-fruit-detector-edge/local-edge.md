# Ваш комп'ютер як периферійний пристрій (локальний варіант)

У демонстрації викладача модель Custom Vision експортується в контейнер, який через Azure IoT Edge розгортається на периферійному пристрої (комп'ютері з Linux, Raspberry Pi або віртуальній машині). IoT-пристрій надсилає йому зображення через локальну мережу, а не в хмару.

Ви вже зробили те саме в [уроці 2](../2-check-fruit-from-device/local-classify-image.md): модель із Teachable Machine працює на вашому комп'ютері, поруч із віртуальним IoT-пристроєм. Ваш комп'ютер і є периферійним пристроєм.

| | Демо викладача (Azure IoT Edge) | Ваш локальний варіант |
| --- | --- | --- |
| Де тренується модель | Custom Vision (хмара) | Teachable Machine (браузер) |
| Формат моделі | Контейнер Docker з моделлю TensorFlow | Файл TensorFlow Lite (`model_unquant.tflite`) |
| Як модель потрапляє на периферію | IoT Edge завантажує контейнер із реєстру контейнерів | Ви копіюєте файл моделі в папку проєкту |
| Як пристрій викликає модель | REST-запит `POST http://<IP address or name>/image` | Виклик `interpreter.invoke()` у тому самому застосунку |
| Чи йде зображення в Інтернет | Ні | Ні |

## Запустіть класифікатор на периферії

### Завдання: класифікуйте зображення на своєму комп'ютері

1. Відкрийте проєкт `fruit-quality-detector` з уроку 2 і запустіть CounterFit.

1. Запустіть код із [local-classify-image.md](../2-check-fruit-from-device/local-classify-image.md) (папка [code-local/virtual-iot-device](../2-check-fruit-from-device/code-local/virtual-iot-device)):

    ```sh
    python app.py
    ```

    ```output
    (.venv) ➜  fruit-quality-detector python app.py
    INFO: Created TensorFlow Lite XNNPACK delegate for CPU.
    ripe:   96.60%
    unripe: 3.40%
    ```

    Зображення з камери не залишає ваш комп'ютер, а класифікація працює навіть без підключення до Інтернету. Це ті самі переваги периферійних обчислень, про які йшлося в уроці: швидкість, робота без зв'язку та приватність.

> 💁 Як і з класифікатором на IoT Edge, зображення, які ви класифікуєте локально, ніде не зберігаються автоматично. Щоб перенавчити модель, вам доведеться зберігати знімки самостійно, як описано в розділі [Покращте модель](../2-check-fruit-from-device/local-classify-image.md#покращте-модель) уроку 2.

😀 Ваш детектор фруктів працює на периферії!
