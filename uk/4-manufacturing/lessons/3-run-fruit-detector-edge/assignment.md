# Запустіть інші сервіси на периферії

> 👩‍🏫 Це завдання потребує Azure (IoT Hub, IoT Edge і Azure Functions), тому його показує викладач або виконують охочі, які мають доступ до Azure.

## Інструкції

На периферії можна запускати не лише класифікатори зображень: на пристрій IoT Edge можна розгорнути все, що можна запакувати в контейнер. Безсерверний код у вигляді Azure Functions, наприклад тригери, які ви створювали в попередніх уроках, теж можна запускати в контейнерах, а отже, і на IoT Edge.

Виберіть один із попередніх уроків і спробуйте запустити застосунок Azure Functions у контейнері IoT Edge. Інструкцію, як це зробити на прикладі іншого застосунку Functions, можна знайти в посібнику [Tutorial: Deploy Azure Functions as IoT Edge modules у документації Microsoft](https://learn.microsoft.com/azure/iot-edge/tutorial-deploy-function).

## Критерії оцінювання

| Критерій | Відмінно | Достатньо | Потребує покращення |
| -------- | --------- | -------- | ----------------- |
| Розгорнути застосунок Azure Functions в IoT Edge | Зміг розгорнути застосунок Azure Functions в IoT Edge і використати його з IoT-пристроєм, щоб запускати тригер за IoT-даними | Зміг розгорнути застосунок Functions в IoT Edge, але не зміг змусити тригер спрацювати | Не зміг розгорнути застосунок Functions в IoT Edge |
