# Керування нічником через Інтернет: віртуальний IoT-пристрій і Raspberry Pi

У цій частині уроку ви надсилатимете телеметрію з рівнем освітлення з Raspberry Pi або віртуального IoT-пристрою на MQTT-брокер.

## Публікація телеметрії

Наступний крок — сформувати JSON-документ із телеметрією й надіслати його на MQTT-брокер.

### Завдання

Опублікуйте телеметрію на MQTT-брокері.

1. Відкрийте проєкт нічника у VS Code.

1. Переконайтеся, що в терміналі активовано віртуальне середовище.

1. Додайте цей імпорт на початок файлу `app.py`:

    ```python
    import json
    ```

    Бібліотека `json` потрібна, щоб записати телеметрію у форматі JSON.

1. Після оголошення `client_name` додайте:

    ```python
    client_telemetry_topic = id + '/telemetry'
    ```

    `client_telemetry_topic` — це MQTT-тема, у яку пристрій публікуватиме рівень освітлення.

1. Замініть вміст циклу `while True:` наприкінці файлу на такий:

    ```python
    while True:
        light = light_sensor.light
        telemetry = json.dumps({'light': light})

        print('Надсилаю телеметрію:', telemetry)
        mqtt_client.publish(client_telemetry_topic, telemetry)

        time.sleep(5)
    ```

    Цей код записує рівень освітлення в JSON-документ і публікує його на MQTT-брокері. Потім програма «засинає» на 5 секунд, щоб не надсилати повідомлення надто часто.

1. Запустіть код так само, як у попередній частині завдання. Якщо ви використовуєте віртуальний IoT-пристрій, переконайтеся, що застосунок CounterFit запущено, а сенсор освітлення й світлодіод створено на правильних пінах.

    ```output
    (.venv) ➜  nightlight python app.py
    Підключено до MQTT!
    Надсилаю телеметрію: {"light": 0}
    Надсилаю телеметрію: {"light": 0}
    ```
