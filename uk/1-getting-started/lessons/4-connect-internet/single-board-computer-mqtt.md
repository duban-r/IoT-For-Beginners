# Керування нічником через Інтернет: віртуальний IoT-пристрій і Raspberry Pi

Щоб обмінюватися даними з *test.mosquitto.org*, IoT-пристрій має працювати з MQTT: надсилати телеметрію з показами сенсора освітлення й отримувати команди для керування світлодіодом.

У цій частині уроку ви підключите Raspberry Pi або віртуальний IoT-пристрій до MQTT-брокера.

## Перед початком: перевірте середовище

### Віртуальний IoT-пристрій (CounterFit)

Застосунок CounterFit давно не оновлювався й жорстко прив'язаний до старих версій Flask та eventlet. На Python 3.12 і новіших він не запускається, а на будь-якій версії Python свіжа інсталяція падає з помилкою `ImportError: cannot import name 'url_quote' from 'werkzeug.urls'`. Виправити це можна, оновивши ці бібліотеки.

1. Відкрийте термінал у папці проєкту `nightlight` з активованим віртуальним середовищем.

1. Виконайте:

    ```sh
    pip install --upgrade CounterFit counterfit-connection counterfit-shims-grove
    pip install "flask==3.1.3" "flask-socketio==5.6.1" "eventlet==0.41.2" "werkzeug==3.1.9"
    ```

    Друга команда виведе попередження на кшталт `counterfit 0.1.4.dev9 requires Flask==2.1.2, but you have flask 3.x`. Це очікувано, на роботу CounterFit воно не впливає.

1. Запустіть CounterFit:

    ```sh
    counterfit
    ```

    У терміналі може з'явитися попередження `Eventlet is deprecated`. Його можна ігнорувати. Відкрийте [http://127.0.0.1:5000](http://127.0.0.1:5000) у браузері й переконайтеся, що сенсор освітлення на піні 0 і світлодіод на піні 5 створено.

> 💁 Ці кроки перевірено на Python 3.11, 3.12, 3.13 і 3.14.

### Raspberry Pi

У Raspberry Pi OS Bookworm (2023) і новіших глобальна команда `pip3 install` заборонена й видає помилку `externally-managed-environment`. Тому на Pi теж потрібне віртуальне середовище. Якщо ви ще не створили його в папці `nightlight`, зробіть це:

```sh
cd ~/nightlight
python3 -m venv --system-site-packages .venv
source .venv/bin/activate
```

Прапорець `--system-site-packages` дає середовищу доступ до системних бібліотек, зокрема до `grove.py`, встановленої в уроці 1.

## Встановіть пакет MQTT-клієнта

Щоб обмінюватися даними з MQTT-брокером, встановіть pip-пакет MQTT-бібліотеки у віртуальне середовище на Pi або на комп'ютері з віртуальним пристроєм.

### Завдання

Встановіть pip-пакет.

1. Відкрийте проєкт нічника у VS Code.

1. Переконайтеся, що в терміналі активовано віртуальне середовище (у запрошенні має бути `(.venv)`).

1. Встановіть MQTT-пакет:

    ```sh
    pip install "paho-mqtt>=2.1"
    ```

## Напишіть код пристрою

Пристрій готовий до програмування.

### Завдання

Напишіть код пристрою.

1. Додайте цей імпорт на початок файлу `app.py`:

    ```python
    import paho.mqtt.client as mqtt
    ```

    Бібліотека `paho.mqtt.client` дає вашому застосунку змогу обмінюватися даними через MQTT.

1. Після оголошення сенсора освітлення та світлодіода додайте такий код:

    ```python
    id = '<ID>'

    client_name = id + 'nightlight_client'
    ```

    Замініть `<ID>` на унікальний ідентифікатор. Він стане назвою цього клієнта пристрою, а пізніше й частиною назв тем, у які пристрій публікуватиме повідомлення та на які підписуватиметься. Брокер *test.mosquitto.org* публічний, ним користується багато людей, зокрема інші учні, які виконують це завдання. Унікальні назви клієнта й тем гарантують, що ваш код не конфліктуватиме з чужим. Цей самий ID знадобиться вам і для серверного коду пізніше в цьому завданні.

    > 💁 Унікальний ID можна згенерувати командою `python -c "import uuid; print(uuid.uuid4())"` або на сайті на кшталт [GUIDGen](https://www.guidgen.com).

    `client_name` — це унікальна назва цього MQTT-клієнта на брокері.

1. Нижче додайте код, який створює MQTT-клієнта й підключає його до брокера:

    ```python
    def handle_connect(client, userdata, flags, reason_code, properties):
        if reason_code.is_failure:
            print('Не вдалося підключитися до MQTT:', reason_code)
            return

        print('Підключено до MQTT!')


    mqtt_client = mqtt.Client(mqtt.CallbackAPIVersion.VERSION2, client_id=client_name)
    mqtt_client.on_connect = handle_connect
    mqtt_client.connect('test.mosquitto.org')
    mqtt_client.loop_start()
    ```

    Цей код створює об'єкт клієнта, підключається до публічного MQTT-брокера й запускає цикл обробки у фоновому потоці, який слухає повідомлення в темах, на які підписано клієнта.

    Функція `handle_connect` викликається, коли брокер відповів на підключення. Параметр `reason_code` показує, чи вдалося підключитися. Наприклад, якщо брокер відхилив клієнта, ви побачите причину в консолі.

    > ⚠️ У старих прикладах (зокрема в оригінальній англомовній версії цього курсу) клієнт створюється як `mqtt.Client(client_name)`. З `paho-mqtt` 2.x такий код падає з помилкою `ValueError: Unsupported callback API version`. Перший аргумент тепер вказує версію API функцій зворотного виклику, а назву клієнта передають як `client_id=`.

1. Запустіть код так само, як у попередній частині завдання. Якщо ви використовуєте віртуальний IoT-пристрій, переконайтеся, що застосунок CounterFit запущено, а сенсор освітлення й світлодіод створено на правильних пінах.

    ```output
    (.venv) ➜  nightlight python app.py
    Підключено до MQTT!
    Рівень освітлення: 0
    Рівень освітлення: 0
    ```

    > 💁 Підключення відбувається у фоновому потоці, тож рядок `Підключено до MQTT!` іноді з'являється не першим.
