# Використайте сертифікат X.509 у коді пристрою: віртуальний IoT-пристрій і Raspberry Pi

> 👩‍🏫 Цю частину показує викладач (демо). Студенти виконують [локальний варіант](local-x509.md).

У цій частині уроку ви підключите віртуальний IoT-пристрій або Raspberry Pi до IoT Hub за допомогою сертифіката X.509.

## Підключіть пристрій до IoT Hub

Наступний крок — підключити пристрій до IoT Hub за допомогою сертифікатів X.509.

### Завдання: підключіться до IoT Hub

1. Скопіюйте файли ключа й сертифіката в папку з кодом IoT-пристрою. Якщо ви працюєте з Raspberry Pi через VS Code Remote SSH, а ключі створювали на своєму ПК чи Mac, файли можна перетягнути в провідник (explorer) VS Code, щоб скопіювати їх.

1. Відкрийте файл `app.py`.

1. Щоб підключитися за сертифікатом X.509, потрібні ім'я хоста IoT Hub і сертифікат X.509. Почніть зі змінної з ім'ям хоста: додайте такий код перед створенням клієнта пристрою:

    ```python
    host_name = '<host_name>.azure-devices.net'
    ```

    Замініть `<host_name>` на назву свого IoT Hub. Повне ім'я хоста можна взяти з частини `HostName` у `connection_string`: це назва вашого IoT Hub, що закінчується на `.azure-devices.net`.

1. Під цим кодом оголосіть змінну з ідентифікатором пристрою:

    ```python
    device_id = 'soil-moisture-sensor-x509'
    ```

1. Вам знадобиться екземпляр класу `X509` з файлами X.509. Додайте `X509` до списку класів, що імпортуються з модуля `azure.iot.device`:

    ```python
    from azure.iot.device import IoTHubDeviceClient, Message, MethodResponse, X509
    ```

1. Створіть екземпляр класу `X509` з файлами сертифіката й ключа, додавши такий код під оголошенням `device_id`:

    ```python
    x509 = X509('./soil-moisture-sensor-x509-cert.pem', './soil-moisture-sensor-x509-key.pem')
    ```

    Цей код створює об'єкт `X509` з файлів `soil-moisture-sensor-x509-cert.pem` і `soil-moisture-sensor-x509-key.pem`, створених раніше.

    > 💁 Шляхи `./...` відраховуються від поточної папки терміналу, тому запускайте `python app.py` з папки, де лежать ці файли.

1. Замініть рядок коду, який створює `device_client` з рядка підключення, на такий:

    ```python
    device_client = IoTHubDeviceClient.create_from_x509_certificate(x509, host_name, device_id)
    ```

    Так пристрій підключатиметься за сертифікатом X.509, а не за рядком підключення.

1. Видаліть рядок зі змінною `connection_string`.

1. Запустіть код. Відстежуйте повідомлення, надіслані в IoT Hub, і надсилайте запити прямих методів, як і раніше. Ви побачите, що пристрій підключається й надсилає показники вологості ґрунту, а також отримує запити прямих методів.

> 💁 Цей код є в папці [code/virtual-device](code/virtual-device). Код для Raspberry Pi є в [оригінальному курсі](https://github.com/microsoft/IoT-For-Beginners/tree/main/2-farm/lessons/6-keep-your-plant-secure/code/pi) (ще не адаптовано, оригінал англійською).

😀 Ваша програма для сенсора вологості ґрунту підключена до IoT Hub за допомогою сертифіката X.509!
