# Публікація температури: віртуальний IoT-пристрій і Raspberry Pi

У цій частині уроку ви публікуватимете через MQTT значення температури, виміряні Raspberry Pi або віртуальним IoT-пристроєм, щоб згодом використати їх для обчислення GDD.

## Публікація температури

Коли температуру зчитано, її можна опублікувати через MQTT для «серверного» коду, який отримуватиме ці значення й зберігатиме їх для обчислення GDD.

### Завдання: опублікуйте температуру

Запрограмуйте пристрій публікувати дані про температуру.

1. Відкрийте проєкт застосунку `temperature-sensor`, якщо він ще не відкритий.

1. Повторіть кроки з уроку 4, щоб підключитися до MQTT і надсилати телеметрію. Ви використовуватимете той самий публічний брокер Mosquitto.

    Для цього потрібно:

    - Встановити pip-пакет MQTT: `pip install "paho-mqtt>=2.1"`
    - Додати код підключення до MQTT-брокера
    - Додати код публікації телеметрії

    > ⚠️ За потреби скористайтеся [інструкціями з підключення до MQTT](../../../1-getting-started/lessons/4-connect-internet/single-board-computer-mqtt.md) та [інструкціями з надсилання телеметрії](../../../1-getting-started/lessons/4-connect-internet/single-board-computer-telemetry.md) з уроку 4.

1. Переконайтеся, що `client_name` відповідає назві цього проєкту:

    ```python
    client_name = id + 'temperature_sensor_client'
    ```

1. У телеметрії замість рівня освітлення надсилайте значення температури, зчитане із сенсора DHT, у властивості JSON-документа з назвою `temperature`:

    ```python
    _, temp = sensor.read()
    telemetry = json.dumps({'temperature': temp})
    ```

1. Температуру не потрібно зчитувати дуже часто: за короткий час вона майже не змінюється. Тому встановіть у `time.sleep` паузу на 10 хвилин:

    ```python
    time.sleep(10 * 60)
    ```

    > 💁 Функція `sleep` приймає час у секундах, тож щоб значення було легше читати, його передають як результат обчислення. У хвилині 60 секунд, отже 10 × (60 секунд у хвилині) дає паузу на 10 хвилин.

1. Запустіть код так само, як у попередній частині завдання. Якщо ви використовуєте віртуальний IoT-пристрій, переконайтеся, що застосунок CounterFit запущено, а сенсори вологості й температури створено на правильних пінах.

    ```output
    (.venv) ➜  temperature-sensor python app.py
    Підключено до MQTT!
    Надсилаю телеметрію: {"temperature": 25.0}
    Надсилаю телеметрію: {"temperature": 25.0}
    ```

    > 💁 Наступне повідомлення з'явиться лише через 10 хвилин. Щоб під час перевірки не чекати так довго, можна тимчасово зменшити паузу, наприклад до `time.sleep(10)`.

Код для Raspberry Pi є в [оригінальному курсі](https://github.com/microsoft/IoT-For-Beginners/tree/main/2-farm/lessons/1-predict-plant-growth/code-publish-temperature/pi) (ще не адаптовано, оригінал англійською; він написаний для `paho-mqtt` 1.x).
