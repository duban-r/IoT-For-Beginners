# Додайте ручне керування реле

## Інструкції

Безсерверний код можуть запускати найрізноманітніші події, зокрема HTTP-запити. За допомогою HTTP-тригерів можна додати ручне керування реле, щоб будь-хто міг увімкнути чи вимкнути реле вебзапитом.

У цьому завданні потрібно додати до застосунку Functions два HTTP-тригери, які вмикають і вимикають реле, використовуючи те, що ви дізналися в цьому уроці про надсилання команд на пристрій.

> 👩‍🏫 Якщо ви виконували [локальний варіант](local-serverless.md) уроку, додайте ручне керування до свого локального коду: напишіть невеликий застосунок на Python, який надсилає команди `{"relay_on": true}` і `{"relay_on": false}` у тему `<ID>/commands` через MQTT, так само як це робить ваша «безсерверна» функція.

Кілька підказок:

* HTTP-тригер у моделі програмування Python v2 — це ще одна функція у файлі `function_app.py` з декоратором `@app.route`:

    ```python
    @app.route(route='relay_on', auth_level=func.AuthLevel.ANONYMOUS)
    def relay_on(req: func.HttpRequest) -> func.HttpResponse:
        ...
        return func.HttpResponse('Реле ввімкнено')
    ```

    Назва Python-функції стає назвою тригера, тож використайте щось на кшталт `relay_on` і `relay_off`.

* HTTP-тригери можуть мати контроль доступу. За замовчуванням для запуску потрібно передати в URL-адресі ключ API конкретної функції. У цьому завданні можна зняти це обмеження, щоб функцію міг запустити будь-хто. Саме для цього в декораторі вище вказано:

    ```python
    auth_level=func.AuthLevel.ANONYMOUS
    ```

    > 💁 Більше про контроль доступу можна прочитати в [документації про ключі доступу до функцій](https://learn.microsoft.com/azure/azure-functions/functions-bindings-http-webhook-trigger#authorization-keys).

* HTTP-тригери за замовчуванням підтримують запити GET і POST. Тобто їх можна викликати з браузера: браузери надсилають запити GET.

    Коли ви запускаєте застосунок Functions локально, ви побачите URL-адресу тригера:

    ```output
    Functions:

        relay_off: [GET,POST] http://localhost:7071/api/relay_off

        relay_on: [GET,POST] http://localhost:7071/api/relay_on

        iot-hub-trigger: eventHubTrigger
    ```

    Вставте URL-адресу в браузер і натисніть `Enter` або клацніть посилання в терміналі VS Code з натиснутою клавішею `Ctrl` (`Cmd` у macOS), щоб відкрити його в браузері за замовчуванням. Так тригер запуститься.

    > 💁 Зверніть увагу, що в URL-адресі є `/api`: HTTP-тригери за замовчуванням розташовані за шляхом `api`.

* Після розгортання застосунку Functions URL-адреса HTTP-тригера буде такою:

    `https://<functions app name>.azurewebsites.net/api/<trigger name>`

    де `<functions app name>` — назва вашого застосунку Functions, а `<trigger name>` — назва тригера.

## Критерії оцінювання

| Критерій | Відмінно | Достатньо | Потребує покращення |
| -------- | -------- | --------- | ------------------- |
| Створення HTTP-тригерів | Створено 2 тригери з відповідними назвами, які вмикають і вимикають реле | Створено один тригер з відповідною назвою | Не вдалося створити жодного тригера |
| Керування реле з HTTP-тригерів | Обидва тригери підключено до IoT Hub, і вони правильно керують реле | Один тригер підключено до IoT Hub, і він правильно керує реле | Не вдалося підключити тригери до IoT Hub |
