## 1. Що зламано

### Python і бібліотеки (головна причина, чому «треба старий Python»)

| Проблема | Де трапляється | Стан | Виправлення |
| --- | --- | --- | --- |
| **CounterFit** (віртуальний пристрій) жорстко прив'язаний до `Flask==2.1.2`, `Flask-SocketIO==5.2.0`, `eventlet==0.33.3`. Свіжа інсталяція падає з `ImportError: url_quote` на будь-якому Python, а на 3.12+ ще й з `No module named 'distutils'` та `ssl.wrap_socket` | Усі уроки з віртуальним пристроєм | **[перевірено]** | Після `pip install CounterFit` виконати `pip install "flask==3.1.3" "flask-socketio==5.6.1" "eventlet==0.41.2" "werkzeug==3.1.9"`. Перевірено на Python 3.12 і 3.14.8: вебінтерфейс і всі сенсори й актуатори курсу (світло, світлодіод, вологість ґрунту, реле, DHT, GPS, камера, відстань). Самоперевірка: `tools/counterfit_selftest.py` |
| **paho-mqtt 2.x** (з лютого 2024): `mqtt.Client(client_name)` падає з `ValueError: Unsupported callback API version` | Розділ 1, урок 4; розділ 2, уроки 1–3 (17 місць у коді й тексті) | **[перевірено]** | `mqtt.Client(mqtt.CallbackAPIVersion.VERSION2, client_id=...)`, підписка в `on_connect` |
| **Raspberry Pi OS Bookworm**: глобальний `pip3 install` заборонено (`externally-managed-environment`), а в курсі прямо написано «на Pi віртуальне середовище не використовується» | Усі уроки з Raspberry Pi | **[за документацією]** | `python3 -m venv --system-site-packages .venv` на Pi |
| **picamera** не працює з сучасним стеком камери (libcamera) | Розділ 4 урок 2, розділ 5 урок 2 | **[за документацією]** | Перейти на `picamera2` |
| Встановлення `grove.py` через скрипт Seeed на Bookworm | Розділ 1, урок 1 (Pi) | потрібна перевірка на залізі | Інсталяція у venv або з git |
| Текст вимагає «Python 3.6 або новіший», приклади з 3.9.1 | Розділ 1, уроки 1 і 4; розділ 2, урок 5 | **[перевірено]** | Мінімум 3.10, рекомендовано 3.14 |

### Помилки в самому тексті

* Символ підстановки MQTT подано як `/telemetry/*`; у MQTT це `+` або `#` (розділ 1, урок 4).
* В існуючому українському машинному перекладі (`translations/uk`) частину розділу 1 уроку 4 втрачено (обрізано розділ «Втрата з'єднання» та «Виклик»), а посилання змісту ведуть у нікуди.
