# Текст у мовлення: локальний варіант без Azure

У варіанті з сервісом Speech функція `say` перетворює текст відповіді на SSML, надсилає його в сервіс і відтворює отриманий звук. У локальному варіанті хмарного сервісу немає, тому відповіді пристрою виводяться текстом у терміналі. Решта коду таймера не змінюється: його логіка однакова для обох варіантів.

## Відповідь пристрою

Усі відповіді таймера проходять через одну функцію `say`. Завдяки цьому спосіб відповіді можна змінити в одному місці: у демо викладач замінює вміст `say` на синтез мовлення, а у вас вона друкує текст.

### Завдання: перевірте відповіді таймера

1. Відкрийте проєкт `smart-timer` у VS Code.

1. Переконайтеся, що функція `say` у файлі `app.py` така, якою ви створили її в [попередній частині уроку](single-board-computer-set-timer.md):

    ```python
    def say(text):
        print(text)
    ```

1. Запустіть застосунок і поставте кілька таймерів українською та англійською. Ви побачите відповідь про запуск кожного таймера, а коли час вийде — повідомлення про завершення:

    ```output
    (.venv) ➜  smart-timer python app.py
    > Постав таймер на 3 секунди
    Ви сказали: Постав таймер на 3 секунди
    Таймер на 3 с запущено.
    > set a timer for one minute and 2 seconds
    Ви сказали: set a timer for one minute and 2 seconds
    Таймер на 1 хв 2 с запущено.
    > Час вийшов! Таймер на 3 с завершено.
    ```

    Щоб зупинити застосунок, натисніть `Ctrl+C`. Якщо ще є незавершені таймери, Python дочекається їх і лише потім завершить роботу. Щоб вийти одразу, натисніть `Ctrl+C` ще раз.
