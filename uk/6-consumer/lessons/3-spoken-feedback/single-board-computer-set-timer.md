# Встановлення таймера: віртуальне IoT-обладнання і Raspberry Pi

У цій частині уроку ви отримаєте з розпізнаного тексту час для таймера й поставите таймер на віртуальному IoT-пристрої або Raspberry Pi.

> 💁 Ці кроки однакові для варіанта з сервісом Speech (демо викладача) і для [локального варіанта](../1-speech-recognition/local-text-input.md), у якому команди вводяться з клавіатури. В обох варіантах у файлі `app.py` є функція `process_text`, і саме її ви змінюватимете.

## Встановлення таймера

Текст, отриманий після перетворення мовлення на текст (або введений з клавіатури), треба передати функції розуміння мови, щоб отримати кількість секунд для таймера. Цю кількість секунд можна використати, щоб поставити таймер.

> 💁 В оригінальному уроці Microsoft текст надсилався HTTP-запитом до безсерверного коду, який обробляв його за допомогою LUIS. LUIS вимкнено 1 жовтня 2025 року, тому в цій адаптації пристрій викликає функцію `text_to_timer`, яку ви написали в [локальному варіанті уроку 2](../2-language-understanding/local-language-understanding.md).

Таймери можна ставити за допомогою класу Python `threading.Timer`. Цей клас приймає час затримки й функцію, і коли час затримки мине, виконує цю функцію.

### Завдання: отримайте час таймера з тексту

1. Відкрийте проєкт `smart-timer` у VS Code і, якщо ви використовуєте віртуальний IoT-пристрій, переконайтеся, що в терміналі активовано віртуальне середовище.

1. Переконайтеся, що файл `text_to_timer.py` з уроку 2 лежить у папці `smart-timer` поруч із `app.py`. Якщо ви створювали його в іншій папці, скопіюйте його сюди.

1. Додайте на початок файлу `app.py` такий імпорт:

    ```python
    from text_to_timer import text_to_timer
    ```

1. Над функцією `process_text` оголосіть функцію `get_timer_time`, яка отримуватиме час для таймера:

    ```python
    def get_timer_time(text):
    ```

1. Додайте в цю функцію такий код, щоб передати текст функції розуміння мови й повернути кількість секунд:

    ```python
        seconds = text_to_timer(text)
        return seconds
    ```

    Функція `text_to_timer` повертає 0, якщо намір встановити таймер не розпізнано.

### Завдання: поставте таймер у фоновому потоці

1. Додайте на початок файлу такий імпорт, щоб підключити бібліотеку Python `threading`:

    ```python
    import threading
    ```

1. Над функцією `process_text` додайте функцію, яка вимовлятиме відповідь. Поки що вона лише виводитиме текст у консоль, а пізніше в цьому уроці озвучуватиме його.

    ```python
    def say(text):
        print(text)
    ```

1. Під нею додайте функцію, яку викликатиме таймер, щоб повідомити, що час вийшов:

    ```python
    def announce_timer(minutes, seconds):
        announcement = 'Час вийшов! Таймер на '
        if minutes > 0:
            announcement += f'{minutes} хв '
        if seconds > 0:
            announcement += f'{seconds} с '
        announcement += 'завершено.'
        say(announcement)
    ```

    Ця функція приймає кількість хвилин і секунд таймера й складає речення про те, що таймер завершився. Вона перевіряє кількість хвилин і секунд і додає кожну одиницю часу, лише якщо вона не нульова. Наприклад, якщо хвилин 0, у повідомленні будуть лише секунди. Потім речення передається функції `say`.

1. Під нею додайте функцію `create_timer`, яка створює таймер:

    ```python
    def create_timer(total_seconds):
        minutes, seconds = divmod(total_seconds, 60)
        threading.Timer(total_seconds, announce_timer, args=[minutes, seconds]).start()
    ```

    Ця функція приймає загальну кількість секунд для таймера й перетворює її на хвилини й секунди. Потім вона створює й запускає об'єкт таймера із загальною кількістю секунд, передаючи йому функцію `announce_timer` і список із хвилинами й секундами. Коли час таймера мине, він викличе функцію `announce_timer` і передасть їй вміст цього списку як параметри: перший елемент списку стане параметром `minutes`, а другий — параметром `seconds`.

1. Додайте в кінець функції `create_timer` код, який складає повідомлення для користувача про те, що таймер запущено:

    ```python
        announcement = 'Таймер на '
        if minutes > 0:
            announcement += f'{minutes} хв '
        if seconds > 0:
            announcement += f'{seconds} с '
        announcement += 'запущено.'
        say(announcement)
    ```

    Тут так само додаються лише ненульові одиниці часу. Потім речення передається функції `say`.

1. Додайте в кінець функції `process_text` такий код, щоб отримати з тексту час для таймера й створити таймер:

    ```python
        seconds = get_timer_time(text)
        if seconds > 0:
            create_timer(seconds)
    ```

    Таймер створюється, лише якщо кількість секунд більша за 0.

1. Запустіть застосунок. Поставте кілька таймерів, і в консолі буде видно, що таймер поставлено, а потім — що він завершився:

    * віртуальний IoT-пристрій або Raspberry Pi із сервісом Speech (демо):

        ```output
        pi@raspberrypi:~/smart-timer $ python3 app.py 
        Постав таймер на 2 хвилини 27 секунд.
        Таймер на 2 хв 27 с запущено.
        Час вийшов! Таймер на 2 хв 27 с завершено.
        ```

    * локальний варіант (команди з клавіатури):

        ```output
        (.venv) ➜  smart-timer python app.py
        > Постав таймер на 2 хвилини 27 секунд
        Ви сказали: Постав таймер на 2 хвилини 27 секунд
        Таймер на 2 хв 27 с запущено.
        > Час вийшов! Таймер на 2 хв 27 с завершено.
        ```

        Повідомлення про завершення таймера з'являється з фонового потоку, тому воно може надрукуватися одразу після запрошення `> `. Ви можете далі вводити команди: таймери працюють незалежно від введення.
