# Розуміння мови: локальний варіант без Azure

У цій частині уроку ви напишете просту функцію розуміння мови на Python. Вона робить те саме, що модель у демо: знаходить у фразі намір `set timer` і сутності «число» та «одиниця часу», а потім обчислює, на скільки секунд ставити таймер.

Справжня модель розуміння мови навчається на прикладах і розуміє фрази, яких ніколи не бачила. Ваша функція простіша: вона знає лише слова, які ви їй задали у словниках. Зате вона працює без Інтернету й облікового запису Azure, і на ній добре видно, що таке наміри й сутності.

## Створення функції розуміння мови

Функція розбиває текст на слова й переглядає їх по черзі:

* якщо слово — число (цифрами, як `30`, або словом, як `три` чи `three`), функція його запам'ятовує;
* якщо одразу після числа йде одиниця часу (`хвилини`, `секунд`, `minutes` тощо), функція записує пару «число + одиниця» як дві сутності.

Якщо знайдено хоча б одну таку пару, намір фрази — `set timer`.

    TIME_UNITS = {
        'minute': ['minute', 'minutes', 'min', 'mins',

1. Додайте функцію, яка повертає нормалізоване значення одиниці часу для слова або `None`, якщо це не одиниця часу:

    ```python
    def find_time_unit(word):
        for time_unit, synonyms in TIME_UNITS.items():
            if word in synonyms:
                return time_unit
        return None
    ```

    Наприклад, для слова `хвилини` вона поверне `minute`, а для слова `таймер` — `None`.

1. Додайте функцію `understand`, яка знаходить у тексті намір і сутності:

    ```python
    def understand(text):
        text = text.lower().replace('’', "'").replace('ʼ', "'")
        words = re.findall(r"[\w']+", text)

        numbers = []
        time_units = []
        number = None

        for word in words:
            time_unit = find_time_unit(word)

            if word.isdigit():
                number = int(word)
            elif word in NUMBER_WORDS:
                value = NUMBER_WORDS[word]
                if number is not None and number >= 20 and number % 10 == 0 and value < 10:
                    number += value
                else:
                    number = value
            elif time_unit is not None and number is not None:
                numbers.append(number)
                time_units.append(time_unit)
                number = None
            else:
                number = None

        intent = None
        if len(numbers) > 0:
            intent = 'set timer'

        return {
            'intent': intent,
            'entities': {
                'number': numbers,
                'time unit': time_units
            }
        }
    ```

    Цей код:

    * переводить текст у нижній регістр і замінює різні апострофи (`’`, `ʼ`) на звичайний `'`, щоб слово `п’ять` збігалося зі словником;
    * регулярним виразом розбиває текст на слова, відкидаючи пробіли, коми, крапки й дефіси;
    * запам'ятовує останнє прочитане число в змінній `number`. Якщо після десятків (`двадцять`) іде одиниця (`п'ять`), вони додаються: 20 + 5 = 25;
    * коли після числа трапляється одиниця часу, додає число в список `numbers`, а одиницю — у список `time_units`;
    * будь-яке інше слово «забуває» запам'ятоване число.

    Функція повертає словник, схожий на відповідь сервісу розуміння мови. Для фрази *«Постав таймер на чотири хвилини 17 секунд»* результат буде таким:

    ```python
    {'intent': 'set timer', 'entities': {'number': [4, 17], 'time unit': ['minute', 'second']}}
    ```

1. Додайте функцію `text_to_timer`, яка перетворює результат розуміння мови на кількість секунд:

    ```python
    def text_to_timer(text):
        prediction = understand(text)

        if prediction['intent'] == 'set timer':
            numbers = prediction['entities']['number']
            time_units = prediction['entities']['time unit']
            total_seconds = 0

            for i in range(0, len(numbers)):
                number = numbers[i]
                time_unit = time_units[i]

                if time_unit == 'minute':
                    total_seconds += number * 60
                else:
                    total_seconds += number

            return total_seconds

        return 0
    ```

    Сутності між собою не пов'язані, але вони йдуть у тому порядку, у якому їх вимовлено. Тому перше число відповідає першій одиниці часу, друге — другій і так далі. Наприклад, для *«Постав таймер на чотири хвилини 17 секунд»* цикл виконається двічі:

    | номер проходу | `number` | `time_unit` |
    | ------------: | -------: | ----------- |
    | 0             | 4        | minute      |
    | 1             | 17       | second      |

    За кожну хвилину до загального часу додається 60 секунд, за кожну секунду — 1. Якщо намір не `set timer`, функція повертає `0`. В оригінальному уроці функція Azure в такому разі повертала HTTP-код 404.
