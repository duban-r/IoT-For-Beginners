# Мовлення в текст: локальний варіант без Azure

У цій частині уроку ви створите проєкт розумного таймера, який отримує команди як текст. Сервіс Speech з основного уроку перетворює мовлення на текст, і далі код працює лише з цим текстом. У локальному варіанті ви пропускаєте мікрофон і хмарний сервіс: вводите команду з клавіатури, ніби сервіс Speech уже розпізнав ваше мовлення. Решта проєкту (розуміння фрази й таймер) працюватиме з цим текстом так само.

## Введення команд з клавіатури

У Python текст із клавіатури читає вбудована функція `input`. Вона чекає, доки користувач введе рядок і натисне Enter, і повертає введений текст.

### Завдання: отримайте текст команди

1. Створіть на комп'ютері новий Python-застосунок у папці `smart-timer` з одним файлом `app.py` і віртуальним середовищем Python, як у попередніх уроках. Встановлювати pip-пакети для цього варіанта не потрібно.

1. Відкрийте папку `smart-timer` у VS Code.

1. Додайте у файл `app.py` функцію, яка обробляє текст команди й виводить його в консоль:

    ```python
    def process_text(text):
        print('Ви сказали:', text)
    ```

    У варіанті з сервісом Speech цю саму функцію викликає розпізнавач щоразу, коли розпізнає фразу. Пізніше ви додасте в неї встановлення таймера.

1. Додайте під функцією нескінченний цикл, який читає команду з клавіатури й передає її функції `process_text`:

    ```python
    while True:
        text = input('> ')
        process_text(text)
    ```

    `input('> ')` виводить запрошення `> ` і чекає, доки ви введете рядок.

1. Запустіть застосунок:

    ```sh
    python app.py
    ```

1. Введіть кілька команд, наприклад `Постав таймер на 3 хвилини 30 секунд` або `Set a 2 minute timer`, і натисніть Enter після кожної. Застосунок виводитиме отриманий текст:

    ```output
    (.venv) ➜  smart-timer python app.py
    > Постав таймер на 3 хвилини 30 секунд
    Ви сказали: Постав таймер на 3 хвилини 30 секунд
    > Set a 2 minute timer
    Ви сказали: Set a 2 minute timer
    ```

    Щоб зупинити застосунок, натисніть `Ctrl+C`.
