# Тести до уроків

Це тести перед лекцією та після лекції для курсу «IoT для початківців». Застосунок написано на Vue 2. Українська мова в ньому вибрана за замовчуванням, але можна перемкнутися на англійську, арабську, бенгальську чи китайську.

Кожен урок має два тести. Нумерація тестів наскрізна: у розділі 1 уроку 4 це тести 7 і 8, тобто `/quiz/7` і `/quiz/8`.

## Що змінено порівняно з оригіналом

* Додано український переклад усіх 48 тестів (`src/assets/translations/uk.json`). Питання про LUIS оновлено: правильна відповідь тепер CLU (Conversational Language Understanding), оскільки LUIS вимкнено 1 жовтня 2025 року.
* Українська мова стала мовою за замовчуванням, а інтерфейс (меню, сторінка «не знайдено») перекладено.
* Виправлено залежності. В оригіналі `package.json` вимагає Vue 3, хоча код написано для Vue 2, тому `npm install` там завершується помилкою. Тут версії Vue, eslint та eslint-plugin-vue узгоджено, і застосунок збирається.

## Запуск на своєму комп'ютері

Потрібен [Node.js](https://nodejs.org) 18 або новіший (перевірено на Node.js 22).

```sh
npm install
npm run serve
```

Відкрийте адресу, яку покаже команда (зазвичай http://localhost:8080), і виберіть тест на головній сторінці.

Зібрати статичну версію для розміщення на сервері:

```sh
npm run build
```

Готові файли з'являться в папці `dist`.

## Розгортання

Ми ще не розгортали цей застосунок, тож посилання на тести в уроках поки ведуть на англомовну версію Microsoft. Застосунок складається лише зі статичних файлів, тому його можна розмістити на будь-якому статичному хостингу, наприклад на Azure Static Web Apps чи GitHub Pages. Файл `public/routes.json` потрібен для Azure Static Web Apps: він перенаправляє всі адреси на `index.html`.
